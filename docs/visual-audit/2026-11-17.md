## Design-system notes (observed baseline)

This patch preserves the existing visual system rather than resetting it:

- **Containers:** shared site `--max:1180px`, article text `--text:780px`; shared `.shell` is `min(calc(100% - 40px), var(--max))`.
- **Sections and hierarchy:** shared section padding is 80 px; cards commonly use 30 px padding and 16–18 px grid gaps. Hero and article headings use responsive `clamp()` sizing with compact line-height and balanced wrapping.
- **Buttons:** shared buttons have a 50 px minimum height, 20 px horizontal padding and pill radius; navigation actions collapse into the menu at tablet/mobile widths.
- **Tables:** technical tables retain their 620 px minimum content width so data remains legible; narrow viewports scroll the table container, not the page.
- **Responsive navigation:** mobile/tablet menu begins below desktop width; the new upper tablet cutoff is 860 px to fit localized navigation without changing content-grid breakpoints.
- **Composition:** existing modular grids, restrained blue accents, dark technical hero panels and light data sections remain. The golden ratio is treated only as a proportion check; no dimensions were changed mechanically.
