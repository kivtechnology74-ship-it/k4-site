# Прототип калькулятора для обратной связи

Отдельная русскоязычная копия калькулятора для сбора замечаний по интерфейсу и предварительным расчётам. Планируемый отдельный адрес: `calc.getworkhorseweb.com`.

- Расчётные функции и числовые значения оставлены как в исходной странице.
- Из 137 профилей исключены 31 запись, в источнике/примечании которой прямо упоминается архив K4. Остальные 106 записей сохранены без изменения; одна из них — демонстрационный пример.
- У копии нет ссылок, аналитики, форм или сетевых вызовов к исходному сайту. Профильные OEM-ссылки сохранены.
- Страница помечена `noindex`; в `dist/_headers` дополнительно задан `X-Robots-Tag` и запрет внешних соединений.
- Это прототип для обсуждения. Он не является инженерным заключением и не должен использоваться для инвестиционных решений.

Перед размещением проверить, что новый Cloudflare Pages проект изолирован от текущей главной страницы Workhorse Web и привязан только к поддомену калькулятора.
