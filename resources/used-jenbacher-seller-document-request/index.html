Used Jenbacher Full Seller Document Request

Pre-purchase document package to request before inspection or deposit

Asset / Project: ______________________________ Seller: ______________________________________ Model / Qty: __________________________________ Location: _____________________________________ Date requested: ________________________________

1. Asset Identity

  • Engine nameplate photo — readable and uncropped
  • Genset nameplate photo
  • Generator nameplate photo
  • Serial numbers for each offered unit
  • Exact engine version / gas configuration
  • Voltage / frequency / rated electrical output
  • Controller / DIA.NE generation and identification
  • Complete equipment list: engine, generator, container and BOP

2. Lifecycle & Service History

  • Year of manufacture and commissioning
  • Current operating hours
  • Number of starts, if available
  • Total lifetime-hour explanation where engine/block was replaced
  • Service book
  • Preventive-maintenance records
  • Major-overhaul reports and invoices
  • List and dates of major component replacements
  • Turbocharger repair/replacement history
  • Generator bearing / rewind / repair history
  • Long-term shutdown and storage periods

3. Operating Data

  • Controller screenshots/export
  • Alarm / trip / shutdown history
  • Recent operating data under load
  • Previous FAT or load-test reports
  • Oil-analysis history
  • Oil consumption information
  • Previous fuel / gas specification
  • Previous site duty / typical load profile

4. Package / BOP Documents

  • Single-line electrical diagram
  • Gas-train documentation / P&ID where available
  • Cooling-system documentation
  • Heat-recovery documentation, if included
  • Container drawings / dimensions
  • Radiator / dry cooler data
  • Switchgear / protection data
  • Packing / included-equipment list

5. Condition & Logistics

  • Current photos: all sides of genset/container
  • Engine / generator / controller / gas train / cooler photos
  • Current status: running / stored / dismantled / rebuilt
  • Reason for decommissioning
  • Preservation / storage records
  • Recent start/run video under load, if available
  • Exact asset location
  • Incoterms / loading responsibility
  • Confirmation of ownership / right to sell

K4 Hold Points Before Deposit

  • Missing or unreadable nameplates
  • Serial/document mismatch
  • Unexplained “low hours”
  • Major overhaul/rebuild claimed without evidence
  • Unknown fuel history
  • Long storage without preservation records
  • Seller refuses inspection / borescope / representative load test

Send the package in one folder with filenames tied to each unit / serial number.
