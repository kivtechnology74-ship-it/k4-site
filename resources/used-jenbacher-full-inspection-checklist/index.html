K4 Used Jenbacher Full Pre-Purchase Inspection Checklist

How to use this checklist

Compare resources
K4 TechnologyPublished: 13.09.2026
OEM DATAFIELD EVIDENCEK4 ANALYSIS

Use it during desk review, seller-document review, physical inspection and FAT / load testing.

For every line mark:

  • PASS — verified by objective evidence and acceptable.
  • CONDITION — acceptable only if a defined condition is satisfied before payment.
  • FAIL — unacceptable and requires remediation, price adjustment or rejection.
  • NOT VERIFIED — evidence is missing; treat as an open risk until resolved or reflected in the transaction terms.

Record the evidence actually reviewed: document name, photograph, nameplate, controller export, test report or inspection record.

Seller statements are inputs. They are not substitutes for evidence.

Minimum Seller Package Before You Travel

Request at minimum:

Asset identity

  • Serial-specific technical description
  • Engine / genset / generator nameplate photographs
  • Exact version / configuration
  • Rated output, voltage and frequency

Lifecycle

  • Commissioning date
  • Known total asset / genset hours
  • Current engine hours
  • Engine / block replacement history
  • Hours since last documented major overhaul

Maintenance

  • Service book
  • Scheduled-maintenance records
  • Overhaul reports
  • Supporting invoices where available
  • Major-component replacement history
  • Oil-analysis history where available

Operating history

  • Controller screenshots / data export
  • Alarm / trip history
  • Previous FAT / load-test reports

Technical configuration

  • Single-line diagram
  • Gas / cooling / heat-recovery documentation
  • Previous-site fuel specification

BOP

  • Included-equipment / packing list
  • Container / package drawings
  • Major auxiliary-equipment data

Storage / preservation

  • Preservation records
  • Current-condition record

Commercial / ownership

  • Price
  • Incoterms
  • Exact location
  • Proof of ownership / right to sell
