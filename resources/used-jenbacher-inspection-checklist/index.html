  • [ ] Piston crowns reviewed
  • [ ] Cylinder-to-cylinder consistency reviewed

  • [ ] Starts recorded where available
  • [ ] Alarm/trip history reviewed
  • [ ] Load profile reviewed
  • [ ] Repeated derating checked
  • [ ] Temperatures/pressures reviewed
  • [ ] Controller history consistent with documents

FAT / Load Test

  • [ ] Acceptance criteria agreed before test
  • [ ] Start/warm-up reviewed
  • [ ] Stable operation demonstrated
  • [ ] Staged loading completed
  • [ ] Agreed high-load/full-load point achieved
  • [ ] Electrical output / PF assessed against agreed criteria
  • [ ] Temperatures / pressures assessed against applicable OEM / agreed criteria
  • [ ] Cylinder/exhaust balance assessed
  • [ ] No unexplained abnormal vibration/noise
  • [ ] No material unexplained leaks
  • [ ] No unexplained alarms/trips
  • [ ] Generator/BOP behaviour reviewed

Fuel / Configuration

  • [ ] Previous fuel identified
  • [ ] Intended fuel specification obtained
  • [ ] Compatibility verified for exact configuration
  • [ ] Gas pressure/treatment requirements checked
  • [ ] Conversion / derating exposure identified
