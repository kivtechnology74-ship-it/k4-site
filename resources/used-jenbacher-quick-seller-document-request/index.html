Used Jenbacher Quick Seller Document Request

Documents to request before inspection or deposit

Compare resources
K4 TechnologyPublished: 13.09.2026
OEM DATAFIELD EVIDENCEK4 ANALYSIS

Please provide the documents and evidence below for the exact units being offered.

If a document is not available, please mark it as unavailable rather than substituting generic information for the model family.

1. Asset Identity

  • Engine nameplate photograph — readable and uncropped
  • Genset nameplate photograph
  • Generator nameplate photograph
  • Serial numbers for each offered unit
  • Exact engine version / configuration
  • Rated electrical output
  • Voltage and frequency
  • Controller / DIA.NE generation where applicable
  • Complete list of equipment included in the sale

2. Lifecycle History

  • Year of manufacture
  • Original commissioning date
  • Current displayed operating hours
  • Known total asset / genset operating history
  • Current engine hours, where different
  • Engine / short-block / long-block replacement history
  • Date and hours of last major overhaul, if claimed
  • Major component replacement history
  • Turbocharger repair / replacement history
  • Generator repair / bearing / rewind history
  • Long shutdown or storage periods

3. Maintenance Records

  • Service book
  • Scheduled maintenance records
  • Overhaul reports
  • Supporting invoices for major repairs where available
  • List of replaced major components
  • Oil-analysis history where available

4. Operating Data

  • Latest controller screenshots or data export
  • Alarm / trip / shutdown history where available
  • Recent operating data under load
  • Previous FAT / load-test reports
  • Previous fuel / gas specification
  • Typical historical load profile, if available

5. Package / Balance of Plant

  • Single-line electrical diagram
  • Gas-train documentation / P&ID where available
  • Cooling-system documentation
  • Heat-recovery documentation, if included
  • Container / package drawings
  • Radiator / dry-cooler data
  • Switchgear / protection information
  • Packing list / exact equipment-inclusion list

6. Current Condition & Storage

  • Current photographs of all sides of the genset / container
  • Engine, generator, controller, gas-train and cooling-equipment photographs
  • Current status: running / stored / dismantled / rebuilt
  • Reason for decommissioning
  • Storage and preservation records
  • Recent run video under representative load, if available
  • Any current-condition / handover report

7. Commercial / Ownership

  • Exact asset location
  • Asking price
  • Incoterms / loading responsibility
  • Confirmation of ownership / right to sell
  • Confirmation that inspection and representative load testing can be arranged

K4 Hold Points Before Deposit

The following items require clarification before payment:

  • unreadable or missing nameplates;
  • serial numbers that cannot be reconciled;
  • documentation that does not match the physical machine;
  • unexplained “low hours”;
  • major overhaul or rebuild claimed without evidence;
  • unknown fuel history;
  • long storage without preservation records;
  • refusal to allow reasonable inspection, borescope or representative load testing.

Missing evidence does not automatically mean the asset is unsuitable.

It does mean the uncertainty should remain open until resolved or reflected in the transaction terms.

Short Message to Forward to the Seller

Hello,

Before we arrange an inspection or proceed with a deposit, please send the documents and photographs listed below for the exact units being offered.

Where a document is not available, a simple note that it is unavailable is sufficient. We want to make sure the technical identity, lifecycle history and sale perimeter are clear before travelling.

Thank you.
