Б/у Jenbacher: краткий запрос документов у продавца

Документы до осмотра или внесения задатка

Все материалы
K4 TechnologyОпубликовано: 13.09.2026
OEM DATAFIELD EVIDENCEK4 ANALYSIS

Просим предоставить перечисленные ниже документы и материалы по конкретным предлагаемым установкам.

Если какого-либо документа нет, лучше прямо отметить его отсутствие, а не заменять его общими материалами по семейству двигателей.

1. Идентичность оборудования

  • Фото шильдика двигателя — читаемое, без обрезки
  • Фото шильдика ГПУ
  • Фото шильдика генератора
  • Серийные номера каждой предлагаемой установки
  • Точная версия / конфигурация двигателя
  • Номинальная электрическая мощность
  • Напряжение и частота
  • Поколение контроллера / DIA.NE, где применимо
  • Полный перечень оборудования, входящего в продажу

2. История жизненного цикла

  • Год производства
  • Дата первоначального ввода в эксплуатацию
  • Текущие показания моточасов
  • Известная суммарная история наработки ГПУ / актива
  • Наработка текущего двигателя, если она отличается
  • История замены двигателя / short block / long block
  • Дата и наработка последнего капремонта, если он заявлен
  • История замены крупных компонентов
  • История ремонта / замены турбокомпрессора
  • История ремонта генератора / подшипников / перемотки
  • Длительные периоды простоя или хранения

3. Сервисные документы

  • Сервисная книжка
  • История планового ТО
  • Отчёты о ремонтах
  • Подтверждающие счета по крупным ремонтам, если доступны
  • Перечень заменённых крупных узлов
  • История анализов масла, если есть

4. Эксплуатационные данные

  • Последние скриншоты или экспорт данных контроллера
  • История аварий / остановов, если доступна
  • Свежие рабочие параметры под нагрузкой
  • Предыдущие FAT / нагрузочные испытания
  • Спецификация предыдущего газа / топлива
  • Типичный исторический профиль нагрузки, если доступен

5. Комплектность / Balance of Plant

  • Однолинейная электрическая схема
  • Документация газовой рампы / P&ID, если есть
  • Документация системы охлаждения
  • Документация утилизации тепла, если входит в комплект
  • Чертежи контейнера / package
  • Данные радиатора / dry cooler
  • Данные РУ / защит
  • Packing list / точный перечень оборудования, входящего в продажу

6. Текущее состояние и хранение

  • Актуальные фотографии ГПУ / контейнера со всех сторон
  • Фото двигателя, генератора, контроллера, газовой рампы и охлаждения
  • Текущий статус: в работе / на хранении / демонтирована / восстановлена
  • Причина вывода из эксплуатации
  • Документы по хранению и консервации
  • Свежий видеозапуск под репрезентативной нагрузкой, если доступен
  • Любой актуальный акт состояния / передачи оборудования

7. Коммерческие данные / собственность

  • Точное местоположение оборудования
  • Цена
  • Incoterms / ответственность за погрузку
  • Подтверждение права собственности / права на продажу
  • Подтверждение возможности организовать осмотр и нагрузочные испытания

K4 Hold Points до внесения задатка

Следующие пункты требуют закрытия до оплаты:

  • отсутствуют или не читаются шильдики;
  • невозможно сверить серийные номера;
  • документы не соответствуют физической машине;
  • необъяснимо низкие моточасы;
  • заявлен капремонт / rebuild без подтверждающих документов;
  • неизвестна история топлива;
  • длительное хранение без документов по консервации;
  • продавец отказывается от разумной инспекции, эндоскопии или испытаний под репрезентативной нагрузкой.

Отсутствие документа само по себе не доказывает, что машина плохая.

Но такой пункт должен оставаться открытым риском, пока он не подтверждён или не отражён в условиях сделки.

Короткий текст для пересылки продавцу

Здравствуйте.

До организации осмотра или внесения задатка просим прислать документы и фотографии из списка ниже по конкретным предлагаемым машинам.

Если какого-то документа нет, достаточно прямо это отметить. Нам важно до выезда сверить техническую идентичность оборудования, историю эксплуатации и точную комплектность сделки.

Спасибо.
