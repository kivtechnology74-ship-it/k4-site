1. Идентичность оборудования

  • Читаемое фото шильдика двигателя без обрезки
  • Фото шильдика ГПУ
  • Фото шильдика генератора
  • Серийные номера каждой предлагаемой установки
  • Точная версия двигателя / газовая конфигурация
  • Напряжение / частота / номинальная электрическая мощность
  • Поколение и идентификация контроллера / DIA.NE
  • Полный перечень оборудования: двигатель, генератор, контейнер и BOP

2. Жизненный цикл и сервисная история

  • Год производства и дата ввода в эксплуатацию
  • Текущие моточасы
  • Количество пусков, если доступно
  • Объяснение суммарной наработки, если двигатель / блок заменялся
  • Сервисная книжка
  • История планового ТО
  • Отчёты и счета по капитальным ремонтам
  • Перечень и даты замены крупных компонентов
  • История ремонта / замены турбокомпрессора
  • История подшипников / перемотки / ремонта генератора
  • Длительные периоды простоя и хранения

3. Эксплуатационные данные

  • Скриншоты / экспорт данных контроллера
  • История аварий / trip / shutdown
  • Актуальные рабочие параметры под нагрузкой
  • Предыдущие FAT / нагрузочные испытания
  • История анализов масла
  • Данные по расходу масла
  • Спецификация предыдущего топлива / газа
  • Режим работы на предыдущей площадке / типичный профиль нагрузки

4. Документация package / BOP

  • Однолинейная электрическая схема
  • Документация газовой рампы / P&ID, если доступна
  • Документация системы охлаждения
  • Документация утилизации тепла, если входит в комплект
  • Чертежи / габариты контейнера
  • Данные радиатора / dry cooler
  • Данные РУ / защит
  • Packing list / точный перечень оборудования в поставке

5. Текущее состояние и логистика

  • Актуальные фотографии ГПУ / контейнера со всех сторон
  • Фото двигателя / генератора / контроллера / газовой рампы / охлаждения
  • Текущий статус: работает / хранится / демонтирована / восстановлена
  • Причина вывода из эксплуатации
  • Документы по хранению / консервации
  • Свежий видеозапуск под нагрузкой, если доступен
  • Точное местоположение актива
  • Incoterms / ответственность за погрузку
  • Подтверждение собственности / права на продажу

K4 Hold Points до задатка

  • Отсутствуют или не читаются шильдики
  • Серийные номера / документы не совпадают
  • Необъяснимо «низкие моточасы»
  • Заявлен капремонт / rebuild без доказательств
  • Неизвестна история топлива
  • Длительное хранение без документов по консервации
  • Продавец отказывается от инспекции / эндоскопии / репрезентативного нагрузочного теста
