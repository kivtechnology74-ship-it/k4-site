隐私政策

生效日期：2026年11月21日

k4-technology.com 由 KIV-Technology d.o.o.（“K4”或“我们”）运营。隐私请求请联系 ceo@k4-technology.com。

数据处理

Cloudflare 提供网站交付、安全防护、Workers 和 D1。为此，Cloudflare 可能处理网络和设备数据，包括 IP 地址。计算器分析接口会临时使用连接 IP 进行频率限制；K4 保存的计算器事件不包含 IP。

分析

分析为可选功能。在您选择“同意分析”之前，GA4 不会加载，计算器分析事件也不会发送到 GA4 或 D1。获得同意后，GA4 会收到页面/营销活动上下文、浏览器/设备信息及网站交互。K4 事件包含事件类型、语言、版本、发动机品牌/型号标识/名称、配置类别及不透明会话/计算标识符；不含项目/场地名称、项目财务或工程参数、表单内容或联系信息。选择存入第一方 cookie 六个月，可通过页脚隐私设置更改。

表单

提交联系或诊断表单时，您填写的信息（联系方式、留言和选择的技术详情）、语言、营销来源及时区会存储在 Cloudflare D1，以便 K4 回复。副本通过已配置的邮件中继发送给 K4 团队。拒绝分析不会影响计算器、PDF 打印或联系表单。只有在同意分析且请求成功保存后，咨询才会与分析计算关联。

保存期限和选择

K4 会在回复请求和保存业务记录所需期间保留咨询。D1 计算器事件用于测量和报告；目前未配置自动过期。GA4 保存期限由 K4 属性设置控制。您可通过页脚拒绝或撤回同意。如需访问、更正或删除，请联系 ceo@k4-technology.com。更改分析选择不会删除已提交的表单。
