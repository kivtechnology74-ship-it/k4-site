K4 Intelligence Terms of Use

Effective date: 26 November 2026

K4 Intelligence is a private internal workflow operated by KIV-Technology d.o.o. It is not offered as a public sign-up service.

Purpose and access

The workflow maintains K4’s technical intelligence database and saves or restores its state using files in a Google Drive folder selected by the account owner. It uses Google Drive’s per-file drive.file authorization. The workflow is available only to people authorized by K4 to use its private GitHub repository and Google account.

Data and authorization

The workflow processes the selected database snapshots to preserve and restore operational state between runs. The account owner controls the Drive folder and may revoke the Google authorization at any time. Revoking access does not automatically remove backups already stored in Drive or GitHub Actions artifacts; those copies can be deleted from the respective services.

Availability

The workflow is provided for K4’s internal operations. Runs may be paused or unavailable, and a successful run should not be treated as a guarantee that every source or external service is available. The workflow reports verification results for each snapshot it creates or restores.

Contact

For questions about K4 Intelligence, contact ceo@k4-technology.com.
