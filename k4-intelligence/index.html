K4 Intelligence

K4 Intelligence is K4’s private workflow for maintaining technical research records and source metadata. It is operated by KIV-Technology d.o.o. and is not a public sign-up service.

What it does

The workflow runs K4’s existing research and technical-source tasks. It preserves the workflow database between runs by saving and restoring verified state snapshots in a Google Drive folder selected by the account owner. The Drive integration uses the per-file drive.file scope and handles only files selected for or created by the application.

Data and controls

Snapshots contain K4 workflow state and technical-source metadata; OEM document contents are not included in the database snapshot. A workflow run may also produce a short-lived recovery artifact in K4’s private GitHub repository. The account owner may revoke Drive authorization and remove stored copies from Google Drive or GitHub.
