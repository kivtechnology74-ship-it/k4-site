# K4 Hybrid Power Calculator

`/gpu-estimate-hybrid-ru/` and `/gpu-estimate-hybrid-en/` are Russian and English interfaces to the same hybrid calculation engine (`engine.js`). They estimate annual grid, gas, solar PV and BESS scenarios with an hourly balance over 8,760 steps, without optimizing dispatch. The calculator remains a preliminary estimate, not engineering advice, a feasibility study or an investment recommendation.

The separate English Free Power Screening tool is at `/power-screening/`. Its screening engine and UI remain in this directory for compatibility and are not part of the hybrid calculation.
